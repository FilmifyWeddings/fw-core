StudioCore Desktop Uploader for macOS (Universal)
==================================================

FEATURES:
- Up to 20x Turbo upload speed for high-resolution galleries
- Direct multi-threaded streaming to cloud storage
- Zero browser timeouts, tab crashes, or interruptions
- Compatible with all macOS versions (Intel & Apple Silicon M1/M2/M3/M4)

HOW TO RUN:
1. Double-click "StudioCore-Uploader.command" in Finder.
2. If macOS displays a security prompt on first launch:
   - Right-click "StudioCore-Uploader.command" -> Click "Open" -> Click "Open".
3. The engine starts instantly and binds to http://127.0.0.1:41789.
4. Keep the Terminal window open while you upload photos in Safari or Chrome!
